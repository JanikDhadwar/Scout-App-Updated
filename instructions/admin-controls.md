# Admin control centre

Open Admin control centre from the navigation or More menu.

Needs attention shows missing pit reports, completed-match reports, current responsible scouts, permanent-owner context, unowned teams, conflicts, handoffs and practice progress.

Members manages ordinary membership. Only Owners can promote/demote Admins or offer ownership transfer.

Assignments manages permanent owners and explicit duties. Reassignment changes responsibility and is recorded; review existing accepted coverage before making changes.

Forms and reports links to existing form builders and report search. Archive forms to retain historical definitions. Removing a report requires a reason and can be reversed. Removed IDs remain reserved so an offline retry cannot resurrect a removed report.

Reports using an unrecognized historical form snapshot are retained for review, not silently discarded or included in analytics. Inspect them and use the reasoned review action to approve legitimate historical evidence.

Shared data controls which structured measurements Scouters can see across the team. Activity shows recorded actions and timestamps. Earlier actions are not retrospectively fabricated.
