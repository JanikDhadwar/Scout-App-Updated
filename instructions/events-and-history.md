# Events and history

The active event is shared across your workspace. Admins manage it in Settings → Events. The top bar displays the active event and has no switch control.

Changing events preserves reports, schedules, assignments, handoffs, photos and picklists. Forms stay available. Older clients with a destructive switch dialog must reload before switching.

My Team and scouting use the configured event rather than replacing it with the next event from Blue Alliance. If no event is configured, ask an Admin to activate one.

Use Settings → Browse event history for read-only team profiles, comparison and permitted evidence from saved events without changing the active event. The report library can also search historical reports. Delayed authorized reports retain their original event when they synchronize. Previously cleared records cannot be reconstructed automatically; consult your backups.
